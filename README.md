## ⚡ ১০ মিনিটে সেটআপ (ফোনেই সব)

### ধাপ ১ — Termux ইনস্টল (২ মিনিট)

> ⚠️ **Play Store-এর Termux ব্যবহার করো না** — সেটা পুরোনো আর কাজ করে না।

1. ব্রাউজারে **[f-droid.org](https://f-droid.org)** → F-Droid apk ডাউনলোড + ইনস্টল
2. F-Droid খুলো → সার্চ **Termux** → ইনস্টল (ধীর হতে পারে, অপেক্ষা করো)
3. Termux খোলো আর এই কমান্ডগুলো দাও (এক লাইন করে):

```bash
pkg update && pkg upgrade -y
pkg install nodejs git unzip -y
termux-setup-storage
```
`termux-setup-storage` দিলে ফোনের স্টোরেজ অ্যাক্সেস চাইবে → **Allow** দাও।

4. **জরুরি:** ফোনের Settings → Apps → Termux → **Battery → Unrestricted** বেছে দাও
   (না দিলে ফোন ঘুমালে Romeo মরে যাবে)

### ধাপ ২ — কোড নামানো (২ মিনিট)

* **A. জিপ ফাইল (সহজ):** চ্যাটে আমি `romeo-bot.zip` দেবো → ফোনে ডাউনলোড → Termux-এ:
```bash
cp /sdcard/Download/romeo-bot.zip ~ && cd ~ && unzip romeo-bot.zip && cd romeo-bot
```

* **B. আমার GitHub/কোড কপি:** আমি ফাইল আলাদা করে পাঠাবো, `nano <filename>` দিয়ে পেস্ট।

### ধাপ ৩ — ইনস্টল (২-৩ মিনিট)

```bash
npm install
```

### ধাপ ৪ — তোমার নাম্বার বসানো (১ মিনিট)

```bash
cp .env.example .env
```

এখন `nano .env` দিয়ে এডিট করতে পারো — অথবা সহজ উপায়, সরাসরি কমান্ড (নিজের নাম্বার বসাও):

```bash
sed -i 's/BOT_NUMBER=.*/BOT_NUMBER=919876543210/' .env
sed -i 's/OWNER_NUMBER=.*/OWNER_NUMBER=919876543210/' .env
```

> **নাম্বারের নিয়ম:** দেশের কোড + ১০ সংখ্যা। কোনো `+`, স্পেস বা ড্যাশ নেই।
> ভারত: `91` + তোমার নাম্বার → যেমন `919876543210`

`nano` ব্যবহার করতে চাইলে: টাইপ শেষে **Volume Down + X**, তারপর **Y**, তারপর **Enter**।
(Termux-এ `Ctrl` = ভলিউম ডাউন বা নিচের এক্সট্রা কি-রো)

### ধাপ ৫ — চালু করো! (১ মিনিট)

```bash
npm start
```

স্ক্রিনে এমন কিছু আসবে:

```
   তোমার পেয়ারিং কোড:  ABCD1234

   (919876543210 নাম্বারের জন্য)

   এখন এই ধাপগুলো করো:
   ১) ফোনে WhatsApp খোলো
   ২) ⋮ মেনু → Linked Devices
   ৩) "Link a Device" টিপো
   ৪) "Link with phone number instead" বেছে নাও
   ৫) ওপরের ৮ অঙ্কের কোডটি টাইপ করো
```

**Termux থেকে বের না হয়ে** WhatsApp খোলো (স্প্লিট স্ক্রিন বা রিসেন্ট অ্যাপ দিয়ে) → কোড টাইপ করো → ✅

```
✅ Romeo অনলাইন!  (919876543210)
```

> কোড ২ মিনিট পরে নতুন করে দেখাবে। কাজ না করলে নতুন কোড নাও।

### ধাপ ৬ — গ্রুপে Romeo-কে ঢোকাও (১ মিনিট)

1. তোমার বন্ধুদের গ্রুপে **Romeo-কে অ্যাড করো** (তোমার নিজের নাম্বারই Romeo)
2. গ্রুপে লিখো: `/id`
3. Romeo একটা ID দেখাবে → সেটা কপি করো, Termux-এ ফিরে:

```bash
sed -i 's|ALLOWED_GROUPS=.*|ALLOWED_GROUPS=120363xxxxxx@g.us|' .env
```
(কমা দিয়ে একাধিক গ্রুপ দেওয়া যায়)

4. **Ctrl+C** দিয়ে বট বন্ধ করো, আবার চালাও:

```bash
npm start
```

5. গ্রুপে `!help` লিখো 🎉

## 🔄 ২৪×৭ চালু রাখা

```bash
termux-wake-lock                      # ফোন ঘুমালেও Romeo জাগ্রত
nohup npm start > bot.log 2>&1 &      # ব্যাকগ্রাউন্ডে চলবে
tail -f bot.log                       # লগ দেখো
```

বন্ধ করতে: `pkill -f "node index.js"`

**ফোন রিস্টার্টের পর অটো চালু করতে চাইলে:** F-Droid থেকে **Termux:Boot** ইনস্টল →
```bash
mkdir -p ~/.termux/boot
echo '#!/data/data/com.termux/files/usr/bin/sh
cd ~/romeo-bot && termux-wake-lock && nohup node index.js > bot.log 2>&1 &' > ~/.termux/boot/start-romeo.sh
chmod +x ~/.termux/boot/start-romeo.sh
```

| সমস্যা | সমাধান |

| পেয়ারিং কোড কাজ করছে না | নাম্বার `91XXXXXXXXXX` ফরম্যাটে আছে তো? কোড ২ মিনিটে রিফ্রেশ হয় — নতুনটা নাও |
| QR দেখতে চাই | `.env` থেকে `BOT_NUMBER=` লাইন মুছে দাও → QR আসবে |
| Romeo কোনো উত্তর দিচ্ছে না | `ALLOWED_GROUPS`-এ গ্রুপ ID ঠিকমতো বসানো আছে? গ্রুপে `/id` লিখে যাচাই করো |
| "লগ আউট হয়ে গেছে" | `rm -rf data/auth_session && npm start` → নতুন করে পেয়ার করো |
| কিছুক্ষণ পর Romeo অফলাইন | Settings → Apps → Termux → Battery: **Unrestricted** + `termux-wake-lock` |
| `npm install` আটকে গেছে | ধীর হতে পারে, ৫-১০ মিনিট দাও। এরর দিলে `npm install` আবার চালাও |
| Node এরর | `node -v` → ২০ বা তার বেশি হতে হবে। না হলে `pkg install nodejs -y` |
| গ্রুপে খুব বেশি উত্তর দিচ্ছে | `.env`-এ `COOLDOWN_MS=10000` বাড়াও |

## 🔐 নিরাপত্তা (নিজের নাম্বার ব্যবহার করছো বলে)

কোডে হার্ড-কোড করা আছে:

1. **হোয়াইটলিস্টের বাইরের চ্যাট ডিক্রিপটই করা হয় না** (`shouldIgnoreJid`)
2. **পুরোনো হিস্ট্রি সিঙ্ক হয় না** (`syncFullHistory: false`)
3. **কোনো মেসেজ ডিস্কে সেভ করা হয় না** — শুধু র‍্যামে অস্থায়ী
4. **থার্ড-পার্টিতে কিছু পাঠানো হয় না** (ফেজ ২-তে শুধু ওই গ্রুপের শেষ কিছু মেসেজ AI-এ যাবে)
5. **কোনো ব্রডকাস্ট/স্প্যাম নেই** → ব্যানের ঝুঁকি খুবই কম

**সেশন ব্যাকআপ:** `data/auth_session/` ফোল্ডার → অন্য ডিভাইসে কপি করলেই আবার লগিন করতে হবে না।
